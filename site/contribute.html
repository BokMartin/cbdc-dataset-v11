Contribute

The dataset is open because we expect to be wrong somewhere. Every cell has a document, a page and a quote — so a disagreement can be specific.

Challenge a cell

Open the project on the map, note the cell, the cited document and page, and open an issue with the passage you think decides it differently. We answer with the contract rule that applies and log the outcome.

Add a document

An official document we missed (decision, consultation, design note, pilot report, law)? Send the official URL and date. It enters the registry as a dated addition (core_v2, core_v3…), never silently into the frozen core.

Translate or check a non-English source

Quotes are kept in the source language. Native readers who can check a quote against its page are the most valuable reviewers we can have.

Reuse

CC BY 4.0 for data and documentation, MIT for code. If you build on the matrix, cite the working paper and the contract version you used; the version is in every file's header.

Issues and pull requests: GitHub repository (link in the footer once public). We do not accept values without a document and page.
