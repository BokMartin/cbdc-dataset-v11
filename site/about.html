About

Martin Bok and Dominik Stroukal, Prague University of Economics and Business (VŠE). The dataset accompanies a measurement-and-data paper in preparation for Data & Policy.

Technical collaborator: an LLM (Claude, Anthropic), supervised by the authors. Every decision on which documents count, on the frame and on the method belongs to the authors.

Contribute

A document we missed. An official document of a competent body (decision, consultation, design note, pilot report, law)? Open an issue on GitHub with the official URL and date. It is added as a dated row, never silently.

A wrong link, title or decision. Open an issue with the document ID shown under "Details" on the documents page.

A translation error. If you read the source language and find an error in one of our published machine translations, open an issue with the document ID and the page.
