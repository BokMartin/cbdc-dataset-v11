# Translation procedure (route D of the language ledger), v12 — 10 Nov 2026

**Decision (MB, 9–10 Nov 2026).** Every non-English document that enters the analysis is translated into English by a second LLM and all later steps (posture layer, F-cells) run on English text only. A translation error is preferred to a language-dependent model bias. No author verifies translations from languages neither reads; each translation is published next to its original with a way to report errors. Where the issuer publishes its own English edition (route B), that edition is the evidence and the machine translation of the original serves only as a benchmark of translation quality.

**Scope.** Non-English documents of T1/T2 projects with decision KEEP / BORDERLINE (priority A) or RECHECK (priority B, translated only if kept); documents with a full issuer English edition are priority RB (not translated) or BENCH (translated only as benchmark): `data/translation/TRANSLATION_QUEUE_<date>.csv`. Tiers: `data/manifest/TIERS_<date>.csv` (T1 ≥ 8 evidence documents, T2 5–7, T3 ≤ 4 not used for the yearly series). Language: page-level detection of every master file, `data/manifest/MASTER_LANGUAGE_<date>.csv` (`scripts/frame/detect_master_language.py`).

**English-edition check (10 Nov 2026).** Before any translation, every queued document was checked for an English edition published by the issuer itself (web search and fetch by five research agents, then verification of the decisive cases in a browser: page counts and SHA-256 of the English files, cross-references between language versions). Result in `data/translation/ROUTE_B_PAIRS.csv` (status, URL, how verified, confidence): of 67 documents, 14 have a full issuer English edition (route B, priority RB: Kazakhstan 6, China 3 governor speeches via BIS, Japan 2 MOF "provisional translations", Russia 2 press releases, Macao annual report), 7 only an English summary or press release (still translated; the summary is recorded), 3 only a third-party translation (not used), 43 none. Only a full edition changes the route. A negative finding is "none found", not proof of absence; confidence is recorded per document. The English editions were fetched on 10 Nov 2026 into the master folder and are registered with SHA-256, page count and the original they belong to in `data/translation/ENGLISH_EDITIONS_<date>.csv` (14 held; the AMCM Annual Report 2025 English version, 394 MB, awaits manual download). They enter the registry as evidence only when the authors keep the original document.

**Steps (each one scripted, each artefact hashed).**
1. *Text layer.* `pdftotext -layout` per page (PDF) or visible text (HTML); no OCR. Scanned or garbled files are listed with `input_mode = ocr_or_pdf` and are not translated from the text layer.
2. *Requests.* `scripts/translation/build_translation_pack.py` cuts each document at page markers into chunks (18 000 characters; 9 000 for zh/ja) and writes one complete user message per chunk. The SHA-256 of every user message, with the SHA-256 of the source file, is registered in `data/translation/TRANSLATION_REQUESTS_<date>.csv`. Source texts stay outside the repository (issuers' copyright).
3. *Translation.* One clean call per chunk: system prompt `pipeline/prompts/translation.system.md` (hash recorded) + the user message; no history, no tools. API: `scripts/translation/translate_api.py` (raw response and call metadata stored per chunk). Manual Playground runs are accepted as interim runs with the settings recorded in `RUN_META.json`.
4. *Checks and assembly.* `scripts/translation/ingest_translations.py` never edits a response. It verifies the echoed header (doc_key, chunk, source SHA-256), the identity and order of all page markers, the END marker (truncation), non-empty pages, length ratio, and the share of pages still not English; a failed chunk is re-run. It assembles `<doc_key>.en.txt` with the pipeline's page markers and writes `data/translation/TRANSLATION_MANIFEST_<run>.csv`: source hash → request hashes → response hashes → hash of the English text, provider, model, interface, date, counts of translator notes `[TN:]` and `[ILLEGIBLE]` marks.
5. *Use.* The English text enters extraction with `route = D` in the language ledger; every claim resting on it keeps that flag, and results are reported with and without route-D evidence.

**What the model does not do.** The model does not compute hashes (it only copies the source hash from the request header, which the check compares); all hashes are computed by the scripts on the stored bytes.

**Quality evidence.** (a) Benchmark pairs (`data/translation/ROUTE_B_PAIRS.csv`): Norges Bank Memos 1/2018, 2/2019, 1/2021, the BoJ pilot report and the Bank of Russia 2021 concept are translated with the same prompt and compared with the issuers' English editions (agreement of the coded cells and statement types, not string similarity). (b) A second-model back-check on a random sample of pages is a planned, separate step. Limits to state in the paper: text-layer errors propagate; legal terms without settled English equivalents are kept in brackets; translations are provisional and unverified by readers of the source language.
